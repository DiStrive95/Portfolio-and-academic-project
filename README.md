# Приветсвую в репозитории Portfolio-and-academic-project!

Он создан для наполнения разными учебными и пет-проектами. 

Каждый проект будет собран в отдельную директорию, внутри которой будет своё описание в файлах README.md.

Для проверки большей части проектов локально потребуется установка Docker Desktop.

Так как прилагаются файлы docker-compose.yml, содержащие порты, логины и пароли, я не создавал файлы `.env`.

Всё настроено для быстрой и лёгкой проверки.
