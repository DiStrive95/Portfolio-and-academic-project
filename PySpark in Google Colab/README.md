# Анализ данных при помощи PySpark.

**Проверить проект можно при помощи Google Colab.**
Для этого потребуется загрузить файл Data Analysis with PySpark.ipynb на платформу, и туда же файл csv в директорию "content".

Для генерации файла csv используется скрипт Generating CSV.py с библиотекой faker. Внутри будут содержаться данные:
- IP-адрес клиента
- Временная метка запроса
- HTTP-метод (GET, POST, etc.)
- URL запроса
- Код ответа (200, 404, etc.)
- Размер ответа в байтах


**В ноутбуке Data Analysis with PySpark.ipynb содержатся дополнительные комментарии.**
