# Анализ пользовательских событий в ClickHouse

## Описание проекта

Проект демонстрирует возможности ClickHouse как OLAP-базы данных для аналитики пользовательских событий. Реализовано хранение сырых событий, агрегация данных для трендового анализа и расчёт ключевых метрик.

SQL-код находится в файле OLAP.sql:

- Создаётся таблица сырых данных, из которой данные удаляются, спустя 30 дней после добавления.
- Создаёт агрегированную таблицу с уникальными пользователями.Данные в ней будут хранится 180 дней для трендового анализа.
- Создаёт материализованное представление, которое будет автоматически обновлять агрегатную таблицу,при вставке данных в таблицу с сырыми данными.
- Вставляет сырые данные.
- Далее идёт запрос, который показывает сколько пользователей вернулись в течение следующих 7 дней.
- Запрос с группировками по быстрой аналитике по дням.


**Для проверки проекта потребуется развернуть docker контейнер.** 
Прилагаю docker-compose. _Порты и прочие настройки нужно изменить самостоятельно, при необходимости._

В терминале в директории необходимо выполнить команду docker-compose up -d для создания и запуска контейнера.

Далее необходимо подключиться к базе данных и запустить скрипт OLAP.sql. Я использовал DBeaver.
