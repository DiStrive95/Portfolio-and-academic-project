# Аудит изменений в PostgreSQL

Сhange_audit.sql содержит SQL код, который:
* Создаёт две таблицы. Первая - с данными о пользователях. Вторя - с данными о изменениях в первой.
* Создаёт триггерные функции по трём полям из первой таблицы. Функции фиксируют изменения во второй таблице.
* Создаёт функцию, которая будет выгружать свежие данные в отдельный csv.
* Настраивает планировщик `pg_cron` для автоматического ежедневного экспорта.


Для проверки проекта потребуется развернуть Docker-контейнер. Прилагаются docker-compose и Dockerfile для сборки.
_Порт и другие настрой базы данных, при необходимости, нужно отредактировать в docker-compose._
В терминале потребуется выполнить две команды:
- docker-compose build для сборки образа;
- docker-compose up -d для создания и запуска контейнера.

Далее необходимо подключиться к базе данных. Я проверял всё при помощи DBeaver.

Для ускоренной проверки работы Сhange_audit.sql, нужно настроить в предпоследней строчке ближайшее время для планировщика. 
После срабатывания, внутри контейнера должен появится файл.Проверить его наличие можно при помощи каманд в терминале:
- docker exec -it postgres_db bash
- ls -la /tmp/users_audit_export_*.csv

### Формат экспортируемого файла

CSV-файл содержит следующие колонки:
- `user_id` — идентификатор изменённого пользователя
- `changed_at` — дата и время изменения
- `changed_by` — пользователь, выполнивший изменение
- `field_changed` — название изменённого поля
- `old_value` — старое значение
- `new_value` — новое значение

Файл будет пустой, т.к. данных нет. При желании можно наполнить таблицу users тестовыми записями, затем их изменить.
