# Архивация неактивных пользователей в MongoDB


Проект предназначен для автоматизации процесса архивации неактивных пользователей в MongoDB. Ежедневно (вручную) запускается скрипт, который находит пользователей, соответствующих критериям неактивности, перемещает их данные в архивную коллекцию и сохраняет отчёт о выполненной операции.

**Критерии архивации:**
- Пользователь зарегистрировался более 30 дней назад;
- Не проявлял активность последние 14 дней.

Для проверки проекта прилагаю docker-compose для развёртывания контейнера с базой данных MongoDB.
Запустить его нужно в терминале командой docker-compose up -d.

Далее необходимо загрузить данные, для этого используется Insert_data.py.

После загрузки можно запусить скрипт Archiving_MongoDB.py:
- Поиск неактивных пользователей - анализируются все документы в коллекции user_events;
- Архивация - все события найденных пользователей перемещаются в коллекцию archived_users;
- Удаление - данные пользователей удаляются из основной коллекции;
- Формирование отчёта - создаётся JSON-файл с результатами в той же директории.
