# ETL Pipeline: PostgreSQL → Airflow → Kafka → ClickHouse

Проект представляет собой ETL пайплайн для переноса данных из операционной PostgreSQL в аналитическое хранилище ClickHouse с использованием Apache Kafka для буферизации и Apache Airflow для оркестрации.

Проверить можно при помощи Docker. Требуется открыть папку в терминале и поднять контейнеры командой `docker-compose up -d`.

Далее нужно зайти в интерфейс Airflow.

Пароль: admin

## DAG реализации

В проекте представлены два варианта DAG для демонстрации разных подходов:

### 1. `pipeline_xcom.py` - Мультизадачный DAG

Использует три отдельные задачи Airflow, связанные через XCom(для построение графа тасок).

**Особенности:**
- Наглядная визуализация этапов в Airflow UI
- Возможность перезапуска отдельных задач
- XCom имеет ограничение по размеру (48KB по умолчанию)
- Не подходит для передачи больших объёмов данных

### 2. `pipeline_single.py` - Однозадачный DAG

Вся логика ETL выполняется в одной Python-функции.

**Особенности:**
- Нет ограничений на объём данных
- Данные передаются через переменные Python (быстрее)
- Менее детальная визуализация в Airflow UI
- При ошибке нужно перезапускать весь пайплайн

### Активация

По умолчанию активен `pipeline_xcom.py`. Чтобы переключиться на однозадачный вариант:

1. Переименуйте `pipeline_single.py` в `pipeline.py`
2. Переименуйте `pipeline_xcom.py` в `pipeline_xcom.py.bak` (или удалите)
3. Обновите DAG в Airflow UI
