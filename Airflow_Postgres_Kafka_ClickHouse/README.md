# ETL Pipeline: PostgreSQL → Airflow → Kafka → ClickHouse

Проект представляет собой ETL пайплайн для переноса данных из операционной PostgreSQL в аналитическое хранилище ClickHouse с использованием Apache Kafka для буферизации и Apache Airflow для оркестрации.

Проверить можно при помощи Docker. Требуется открыть папку в терминале и поднять контейнеры командой `docker-compose up -d`.

Далее нужно зайти в интерфейс Airflow.

http://localhost:8080

Логин: admin

Пароль: admin

_Параметры могут отличаться, если были внесены изменения в docker-compose._

При первом запуске dag-а произойдёт перенос тестовых данных из PostgreSQL в ClickHouse. И далее airflow будет проверять наличие новых записей в топике Kafka каждые 5 минут. Если новых записей нет, то и переноса не будет.

Код в pipeline.py содержит дополнительные комментарии.
